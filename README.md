# 🎮 Guess The Number

A simple number guessing game built with **C++ and Qt Widgets**.

This is my first GUI project and one of my first steps into software development.

## 🛠️ Technologies Used

- C++
- Qt Widgets
- Qt Creator
- CMake

## 📥 Download & Play

1. Go to the [Releases](https://github.com/anoudmohammed701-cmd/Guess-The-Number/releases) page.
2. Download `Guess_The_Number_Release.zip`.
3. Extract the ZIP file.
4. Open the extracted folder.
5. Run `firstapp.exe` to start the game.

**Note:** The downloadable version is designed for Windows. You do not need Qt Creator to play it.
